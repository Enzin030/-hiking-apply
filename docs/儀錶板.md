# 系統規格書：營運儀表板 (Dashboard)

## 1. 模組概述
* **模組名稱：** 後台首頁_營運儀表板 (Dashboard)
* **目標受眾：** 總管理者 (Global Admin)、各園管理者 (Park Admin)。
* **核心價值：** 以極簡介面呈現核心 KPI 與待辦事項，提升各園區審核與資源分配效率。

## 2. 角色權限與視圖邏輯 (RBAC)
| 角色層級 | 資料可視範圍 (Data Scope) | UI 控制項差異 (UI Behavior) |
| :--- | :--- | :--- |
| **總管理者** | 全區 (所有國家公園) | 「管理單位」下拉選單預設為 `[全部單位]`，可自由切換。 |
| **各園管理者** | 僅限所屬園區 | 「管理單位」下拉選單強制鎖定 (Disabled) 為所屬單位，或隱藏。 |

---

## 3. 頁面功能規格

### 3.1 全局數據篩選器 (Global Filter Bar)
* **UI 佈局：** 位於頁面頂部，白色背景，底部帶有極淡的灰線 (`border-bottom`)。
* **欄位 1：管理單位 (Dropdown)**
  * **資料來源：** 單位主檔 API。
  * **行為：** 依據 RBAC 決定鎖定狀態。
* **欄位 2：查詢期間 (Date Range Picker)**
  * **預設值：** 系統當日 (Today)。
* **操作按鈕：**
  * `<button class="btn-primary"> <i class="bi bi-search"></i> 查詢 </button>`
  * `<button class="btn-outline"> <i class="bi bi-download"></i> 匯出報表 </button>`

### 3.2 營運數據卡片區 (KPI Cards)
採用 4 欄式 (Col-3) 卡片佈局，純白底色，無過度陰影。

1. **今日申請隊伍數 (Total Applications)**
   * **Icon:** `<i class="bi bi-file-text text-primary"></i>`
   * **UI 狀態：** 顯示期間內送出的申請單總數。若較昨日成長，顯示 `<i class="bi bi-arrow-up-right text-success"></i>`。
2. **待處理案件 (Pending Reviews)**
   * **Icon:** `<i class="bi bi-clock-history text-warning"></i>`
   * **UI 狀態：** 狀態為「待初審」或「待複審」的總數。數值大於 0 時，數字強調顯示。
3. **設施滿載警示 (Capacity Alerts)**
   * **Icon:** `<i class="bi bi-exclamation-triangle text-danger"></i>`
   * **UI 狀態：** 顯示當日承載量達 100% 的宿營地。無滿載時顯示「目前無滿載設施」(淺灰色字體)。
4. **違規攔截數 (Violation Intercepts)**
   * **Icon:** `<i class="bi bi-shield-slash text-secondary"></i>`
   * **UI 狀態：** 申請名單中比對中「黑名單」的自動攔截件數。

### 3.3 數據統計列表 (Data Grid)
* **UI 規範：** * 表頭固定 (Sticky Header)，背景色設為極淺灰 (`#F8F9FA`)。
  * 數值欄位一律**靠右對齊**。數值為 `0` 時，字體顏色設為淺灰色 (`#BDBDBD`)。
  * 支援點擊表頭切換排序 `<i class="bi bi-arrow-down-up"></i>`。
* **資料欄位：** 主路線名稱 | 次路線名稱 | 申請隊伍 | 申請人數 | 核准隊伍 | 核准人數
* **分頁機制：** 底部提供前端分頁組件，預設每頁 20 筆。

## 4. API 與資料結構定義 (Data Schema)

**API: `POST /api/v1/dashboard/summary`**

**Request Payload:**
```json
{
  "parkId": "string (UUID or 'ALL')", 
  "startDate": "YYYY-MM-DD",
  "endDate": "YYYY-MM-DD"
}
