## 一、展示頁

> 功能路徑：首頁 > 山域事故統計儀表板 / 快捷選單 > 學習登山者 > 山域事故儀表板  
> 頁面網址：MountainDashboard.aspx

![山域事故統計儀表板-展示頁](assets/山域事故統計儀表板-展示頁.png)

- 查詢條件：變更任一下拉選單即更新圖表，無查詢按鈕。
  - 分類：下拉選單，選項為山域事故原因分類（預設）、山域事故登山路線分類、申請/實際入園隊伍數及總人數；變更時切換次層篩選項目並更新圖表。
  - 次層篩選（依分類動態顯示）：
    - 分類為「山域事故原因分類」時顯示「事故原因」：下拉選單，選項為全部（預設）、迷路、遲歸、墜谷、疲勞、高山症、疾病、落石、創傷、天氣惡劣、動物攻擊、落雷、其它、不明。
    - 分類為「山域事故登山路線分類」時顯示「管理處」：下拉選單，選項為太魯閣（預設）、玉山、雪霸。
    - 分類為「申請/實際入園隊伍數及總人數」時無次層篩選。
  - 年度：下拉選單，選項為全部（預設）、109、110、111、112、113、114。
- 統計圖表：長條圖。
  - 山域事故原因分類：
    - 橫軸：管理處（太魯閣、玉山、雪霸）。
    - 數列：每個事故原因一個數列，分組長條；事故原因選「全部」時 13 個數列，選定單一原因時僅該原因。
    - 縱軸：案件數。
    - 圖例：位於圖表下方，點擊圖例項可切換顯示/隱藏該數列。
  - 山域事故登山路線分類：
    - 圖表標題：所選管理處名稱。
    - 橫軸：該管理處的各登山路線，標籤斜 45 度。
    - 數列：單一數列，每根長條依序取色；無圖例。
    - 縱軸：案件數。
  - 申請/實際入園隊伍數及總人數：
    - 橫軸：管理處（太管處、玉管處、雪管處）。
    - 數列：申請人數、申請隊伍數兩個數列，分組長條。
    - 縱軸：數量。
    - 圖例：位於圖表下方，點擊可切換顯示/隱藏。
  - 滑鼠移至長條：顯示該管理處（或路線）各數列數值。
  - 查無資料：所選條件無資料時，不顯示圖表，改顯示「查無資料」。
- 資料表
  - 檢視資料表：可展開/收合，以表格列出目前圖表的全部數值。
    - 山域事故原因分類：欄位為事故原因、太魯閣（件）、玉山（件）、雪霸（件）。
    - 山域事故登山路線分類：欄位為登山路線、案件數。
    - 申請/實際入園隊伍數及總人數：欄位為項目、太管處、玉管處、雪管處。

## 內部註記

- 舊系統技術架構：ASP.NET WebForms（`.aspx`）＋ UpdatePanel（`con_UpdatePanel2`）。
- 圖表套件：舊系統為 Chart.js（`js/chart.js`）；雛形改用 ECharts 5.6.0（CDN 載入、integrity 釘版），呈現方式照舊系統三支繪圖函式。
- 控制項識別碼（舊系統）：
  - 分類下拉選單：`ctl00$con$MountainAccType`（`#con_MountainAccType`）。
  - 事故原因下拉選單：`ctl00$con$ddlReason`（`#con_ddlReason`，容器 `#con_pnlReason`）。
  - 管理處下拉選單：`ctl00$con$ddlOrgid`（`#con_ddlOrgid`）。
  - 年度下拉選單：`ctl00$con$ddlYear`（`#con_ddlYear`，容器 `#con_Panel1`）。
  - 圖表資料隱藏欄位：`ctl00$con$hfChartData`（`#con_hfChartData`，儲存圖表 JSON 字串）。
  - 圖表型態隱藏欄位：`ctl00$con$hfChartDataType`（`#con_hfChartDataType`），值為 `A`（原因分類）、`B`（路線分類）、`C`（申請隊伍數）。
  - 圖表容器：`#chartContainer`，畫布 `#accidentChart`。
- 前端繪圖邏輯（舊系統）：
  - 頁面載入或 UpdatePanel 異步更新結束後，調用 `loadChartFromHiddenField()`。
  - 讀取 `#con_hfChartData` 之 JSON 字串：
    - JSON 為陣列（路線分類）：`initOrUpdateChart3(chartData)`，每個元素一張圖，元素為 `{ name, labels, colors, values }`。
    - `hfChartDataType` 為 `C`（申請隊伍數）：`initOrUpdateChart2(chartData)`，縱軸標題「數量」。
    - 其餘（原因分類）：`initOrUpdateChart(chartData)`，縱軸標題「案件數」。
    - 非陣列時 JSON 為 `{ labels, colors, parks: [{ name, values }] }`。
- 色票：15 色，依序為 `#1F3A5F`、`#274A73`、`#2F5D8C`、`#3A6EA5`、`#4A7FB5`、`#6B8A5D`、`#7FA174`、`#95B88E`、`#D36B4A`、`#E08A6C`、`#C4A484`、`#B0B7C3`、`#E5E7EB`、`#CCFF33`、`#FFFF00`。原因分類用前 13 色（單一原因沿用原位色），路線分類依序循環，申請隊伍數用第 1、9 色。雛形收為 `tokens.css` 的 `--chart-cat-1`～`--chart-cat-15`。
- 雛形資料：`05_Prototype/components/AccidentDashboardData.js`，為 2026-09-14 自舊系統逐一切換全部篩選組合擷取的快照。
